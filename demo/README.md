# Datos de demostracion

`invoices.json` conserva las facturas de prueba, productos, PIN y estados actuales.
`facturas_y_pines.csv` contiene las 50 facturas aleatorias y sus PIN.
Estos datos son ficticios y se importan una sola vez si la tabla de facturas esta vacia
y `APP_DEMO_ENABLED=true`. Los reinicios no restablecen entregas ni borran datos.
